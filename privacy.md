# Privacy Policy

Last updated: August 30, 2026

This Privacy Policy applies to Blockdia websites and services under `blockdia.com`, unless otherwise stated.

## Analytics

Some Blockdia services use Cloudflare Web Analytics to help us understand website usage and performance, including page views, page load performance, and Core Web Vitals.

Cloudflare Web Analytics is designed to operate without cookies or local storage for tracking visitors and does not use cross-site tracking or visitor fingerprinting.

For services where Cloudflare Web Analytics is enabled, we currently configure it to exclude analytics collection from visitors in the European Union.

Not all Blockdia services use analytics. In particular, `blockdia.com` itself currently does not use Cloudflare Web Analytics.

## Feedback and Diagnostics

Some Blockdia services allow you to submit feedback, such as indicating whether a feature or code snippet was helpful.

When you submit feedback, we may collect the feedback you provide together with limited diagnostic information, such as a randomly generated browser identifier, coarse device information, and approximate regional information. This information is used to understand feedback, diagnose problems, and improve Blockdia services.

Blockdia does not intentionally retain your IP address or precise location as part of these feedback records.

Additional information about the data associated with a feedback submission may be shown directly in the relevant interface before or when feedback is submitted.

## Server and Infrastructure Data

Some infrastructure providers may process limited technical information, such as IP addresses, request metadata, and security-related information, as necessary to deliver, protect, and operate Blockdia services.

This information may be processed by infrastructure providers such as Cloudflare or GitHub, depending on how a particular Blockdia service is hosted.

## Third-Party Services

Blockdia may rely on third-party infrastructure and services to host or deliver parts of the project. These providers process information according to their own privacy policies.

Examples may include:

- Cloudflare
- GitHub

## Changes to This Policy

We may update this Privacy Policy when Blockdia services, infrastructure, or data practices change.

Significant changes will be reflected on this page by updating the date above.

## Contact

If you have questions about this Privacy Policy, you can contact the Blockdia project through its public project repositories or other official Blockdia communication channels.
